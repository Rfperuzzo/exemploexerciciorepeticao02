# Soma de 10 Números

Programa em Java que lê 10 números informados pelo usuário e realiza a soma de todos eles.

## Objetivo

Praticar:

- Estrutura de repetição `for`
- Entrada de dados com `Scanner`
- Uso de variável acumuladora
- Operações de soma
- Exibição de resultados no console

## Funcionamento

O programa:

1. Solicita um número ao usuário
2. Repete esse processo 10 vezes
3. Soma cada número digitado em uma variável acumuladora
4. Exibe o resultado final da soma

## Lógica utilizada

A variável `soma` começa com valor `0`.

A cada repetição é feito:

```java
soma = soma + num;
